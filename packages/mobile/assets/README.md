# App icons (mobile)

Canonical icon assets for the React Native / Expo app, named to the Expo
convention so they drop straight into `app.json` when Phase 5 starts.

| File | Usage | Source |
| --- | --- | --- |
| `icon.png` | iOS / Android app icon (1024x1024, no alpha) | `AppIcons-option-2/AppIcon.icon/Assets/icon.png` |
| `adaptive-icon.png` | Android adaptive-icon foreground (1024x1024) | `AppIcons-option-2/android/adaptive-foreground.png` |

## Wiring (when the app is scaffolded)

In `app.json`:

```json
{
  "icon": "./assets/icon.png",
  "android": {
    "adaptiveIcon": {
      "foregroundImage": "./assets/adaptive-icon.png",
      "backgroundColor": "#ffffff"
    }
  }
}
```

Then run `npx expo prebuild --clean` to regenerate the platform icon sets.
